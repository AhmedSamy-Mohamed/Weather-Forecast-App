# Weather Forecast App

A desktop weather application built with **C++** and **Qt Widgets** as a practical project during my Software Engineering Diploma.

## Project Overview

Weather Forecast App is designed to provide weather information through a desktop graphical user interface. The project was developed to practice C++ application development and GUI design with Qt.

## Features

- Select a city from the application interface.
- Request and display current weather information.
- Present forecast information in a table.
- Organize weather information in a desktop GUI.

> The exact features and data shown depend on the current implementation of the application.

## Technologies

- **C++**
- **Qt Widgets**
- **CMake**

## Getting Started

1. Clone or download this repository.
2. Open the project folder in **Qt Creator**.
3. Configure the project using the available `CMakeLists.txt` and an installed compatible Qt kit.
4. Build and run the application.

Setup details may vary depending on your Qt version and development environment.
